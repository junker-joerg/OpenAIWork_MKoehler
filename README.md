## Neon Trade Tycoon (Python TUI)

Eine kleine Wirtschaftshandelssimulation mit schickem Text-Interface und Tastensteuerung.

### Start

```bash
python3 trade_sim.py
```

### Steuerung

- `↑/↓`: Ware auswählen
- `W/S`: Zielstadt auswählen
- `B`: Ware kaufen
- `V`: Ware verkaufen
- `T`: In ausgewählte Stadt reisen
- `R`: Treibstoff tanken
- `D`: Schulden tilgen
- `N`: Nächsten Tag starten (Marktpreise ändern sich)
- `Q`: Spiel beenden

> Empfohlenes Terminal: mindestens `100x32` Zeichen.
