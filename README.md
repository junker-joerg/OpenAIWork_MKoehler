# OpenAIWork2025
Arbeitsverzeichnis für OpenAI Codex

## Haushaltsbuchhaltung

`bookkeeping.py` ist eine kleine Anwendung zur Erfassung von Buchungssätzen in einem einfachen doppelten Buchhaltungsrahmen. Die Textoberfläche basiert auf dem Python-Paket `rich` und verwaltet 25 Konten. Alle erfassten Buchungen können als CSV-Datei exportiert werden.

Starten Sie das Programm mit:

```bash
python3 bookkeeping.py
```

Für die Ausführung wird das Paket `rich` benötigt.
